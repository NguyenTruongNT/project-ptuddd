# Inter

Original static TTFs (Regular, Medium, SemiBold, Bold) from the upstream
[Inter 4.1 release](https://github.com/rsms/inter/releases/tag/v4.1),
`Inter-4.1.zip`, `extras/ttf/`. Artwork and font files are unmodified.

License: SIL Open Font License 1.1, included in `LICENSE.txt` from that release.
Used locally on Auth screens, including Vietnamese glyphs; no runtime font CDN.
